# دستور هویت بصری و اجرای دقیق

**اولویت قطعی تصویر `00_APPROVED_STYLE_MASTER.png` است؛ پنج بورد بعدی نمونه‌های مکمل‌اند.**

## معیارهای بصری
- صحنه‌پردازی کامل با آسمان و تپه و گیاهان لطیف، نه صفحه تخت یا گرادیان خالی.
- طراحی شاد و سه‌بعدی؛ آیکون اختصاصی clay 3D با نورپردازی، سایه نرم و عمق واقعی. ایموجی یونیکد دارایی تولیدی محسوب نمی‌شود.
- کارت‌های نیمه‌شفاف لایه‌دار؛ اندازه‌های لمسی مناسب، داک شیشه‌ای و ویجت‌های واقعی.
- شخصیت ربات سبز/سفید و شخصیت‌های مناسب رده سنی؛ دختر با روسری یا پوشش کامل موی سر و هماهنگ با فرهنگ ایرانی اسلامی.
- جنسیت قالب محدودکننده محتوای آموزشی نیست. طرح‌ها به صورت پیش‌فرض قابل انتخاب‌اند و والدین می‌توانند رنگ و شخصیت را تغییر دهند.
- برای نوجوانان از چهره و چیدمان بالغ‌تر، تراکم بیشتر و تم‌های تیره‌تر اختیاری استفاده کن، بدون عناصر نوزادانه.
- آرت‌بوردهای ساخته‌شده توسط هوش مصنوعی می‌توانند ایراد نوشتاری یا ترکیب نامنظم داشته باشند؛ متون فارسی را از نیازمندی و منابع اپ بگیر، نه با OCR از بوردها.
- از بریدن شخصیت‌ها یا آیکون‌ها از پوسترهای دارای متن برای انتشار نهایی اجتناب کن؛ دارایی اصلی جداگانه و قابل استفاده مجدد طراحی کن.

## هماهنگی با پلتفرم
- Material 3 / Compose با layoutDirection راست به چپ. اجزای رابط باید semantics و touch target مناسب داشته باشند.
- حفظ وضعیت و اطلاعات فرزندان، کنترل والدین، محدودیت استفاده، پخش، اجازه‌ها و مسیر بازگشت امن.
- محدودیت‌های Android device owner، overlay، accessibility و launcher را صادقانه ارزیابی کن؛ ادعای قفل غیرقابل دور زدن نکن.
- صفحه تنظیمات والدین باید ظاهری سفید و آرام با چگالی خوانا داشته باشد و عین پوستر کودک رنگارنگ نشود.
