# معیار تحویل و بازبینی

تا وقتی موارد زیر برقرار نیستند، کار را Done اعلام نکن:

- [ ] سورس اصلی، Manifest، ناوبری و وابستگی‌های Android بررسی و ثبت شده‌اند.
- [ ] هیچ سرویس، صفحه یا کنترل ایمنی موجود حذف نشده است.
- [ ] همه ۵۸ مسیر در Navigation قابل دسترسی هستند و حالت‌های خطا/خالی/بارگذاری دارند.
- [ ] تصویرسازی هر بخش مستقل و هم‌سطح بورد مرجع است؛ بدون ایموجی و placeholder بصری.
- [ ] تفاوت رده‌های سنی در ساختار و تراکم قابل مشاهده است؛ دو ظاهر دختر/پسر بدون محدودیت محتوایی اجرا شده‌اند.
- [ ] دختران در تمام تصاویر تولیدی پوشش موی متناسب دارند.
- [ ] هر صفحه در ۳۶۰×۸۰۰dp و اندازه بزرگ‌تر بدون overflow بررسی شده است.
- [ ] هر صفحه در روشن/تاریک/شب و RTL بررسی شده است.
- [ ] محافظت‌های والدین به صورت واقعی تست شده‌اند و هیچ قفل امنیتی جعلی نمایش داده نمی‌شود.
- [ ] از هر صفحه در Compose اسکرین‌شات و گزارش اختلاف با مرجع تهیه شده است.
- [ ] پروژه روی دستگاه یا شبیه‌ساز اجرا می‌شود و خطاهای Build رفع شده‌اند.
- [ ] دارایی‌های خارجی مجوز استفاده و منبع مشخص دارند.

**نکته:** تست کامل ماتریس ۵۸ × ۴ سن × ۳ تم × سبک‌های بصری به برنامه تست مبتنی بر نمونه‌برداری و پوشش ریسک نیاز دارد؛ تیک‌زدن دستی یک اسکرین‌شات برای هر ترکیب کافی نیست.
