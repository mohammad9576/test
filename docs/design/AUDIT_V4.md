# ممیزی پروژه و گزارش اختلاف با بسته‌ی طراحی V4

**سورس واقعی Android موجود است** (`android/`، Kotlin + Jetpack Compose + Hilt + Room)؛ بازطراحی روی همین سورس انجام می‌شود، نه APK.

## فاز ۰ — ممیزی (وضعیت فعلی)
| حوزه | پیاده‌سازی فعلی |
|---|---|
| ورود برنامه | `kiosk/KidsLauncherActivity` (LAUNCHER + HOME)، `FakeHomeActivity` غیرفعال، حالت دمو برای تست شبیه‌ساز (`demo_route`) |
| ناوبری | `ui/navigation/KodomoNavHost.kt` و `Routes.kt` — ۵۲ مسیر؛ همه‌ی صفحه‌های کودک داخل `KidSpaceFrame` |
| ایمنی | `AppGuardService` (Usage Access، بازگرداندن از تنظیمات/نصب‌کننده)، `ReturnBubble` (Overlay)، `KodomoDeviceAdminReceiver` (قفل گوشی هنگام غیرفعال‌سازی)، `DeviceOwnerManager` (LockTask و محدودیت‌ها فقط در حالت Device Owner)، `InternetBlockVpn`، `DataQuota`، `ScreenTimeManager` (سقف روزانه، خواب، مدرسه، نوبت‌ها، جایزه/جریمه) |
| اجازه‌ها | `ui/setup/PermissionSetupScreen.kt` + Manifest (دوربین، میکروفون، تماس، اعلان، باتری، VPN، بیومتریک) |
| داده | Room (`KodomoDatabase` v4)، DataStoreهای Wellbeing/Modules/Approvals/Contacts/Planner/KidMedia/Chores/Learning |
| شبکه | kodoumo.ir API، سرویس‌ها در WebView قفل‌شده (`LockedWebPlayer`) |
| UI قبلی | تم Material3 + `ui/fx` (ایموجی سه‌بعدی Fluent، پس‌زمینه) |

## محدودیت‌ها (صادقانه)
- **تولید تصویر هنری در این محیط ممکن نیست** (ابزار ساخت تصویر در دسترس نیست و CDN پکیج‌های آیکون سه‌بعدی مسدود است). شخصیت‌ها و صحنه با کد Compose و سایه‌زنی نرم «سه‌بعدی‌نما» ساخته شده‌اند، نه رندر واقعی clay.
- برای رسیدن به کیفیت دقیق بوردها: شخصیت‌ها، ربات در حالت‌های مختلف، آیکون‌های بخش‌ها و لایه‌های پس‌زمینه باید **جداگانه با پس‌زمینه‌ی شفاف (PNG/WebP)** ساخته و در `android/app/src/main/assets/art/` قرار گیرند (فهرست در `ASSET_REQUEST_FA.md`).
- قفل کامل نوار اعلان/تنظیمات سریع فقط در حالت Device Owner ممکن است.
