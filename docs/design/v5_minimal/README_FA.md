# کدومو ـ بازطراحی مینیمال نسخه۵

فایل شروع: `START_HERE_FA.md`؛ متن آماده ارسال به کلاد: `PROMPT_FOR_CLAUDE_FA.md`؛ گالری: `GALLERY.html`.

این نسخه پاسخ به اصلاح کارفرماست: شخصیت‌های سه‌بعدی حفظ شوند، صفحات خلوت و مدرن شوند، والدین از سادگی آیفون، کودک از روانی Samsung Kids و نوجوان از سادگی پیمایش اینستاگرام/واتساپ/تلگرام الهام بگیرد. مرجع تقلید ظاهری برندها نیست؛ الگوی استفاده سریع و روشن است.

## محتویات
- ۱۵ بورد جدید برای تمام۵۸صفحه اصلی، هرکدام با نمای روز و شب.
- ۴ بورد اولویت‌دار برای والدین، کودک، نوجوان و گروه‌های سنی.
- ۵ بورد تکمیلی: دو بورد بازی، قفل‌ها، راه‌اندازی و مؤلفه‌ها/توقف بازی.
- ۴ شیت کاراکتر تأییدشده قبلی، بدون تغییر فایل اصلی.
- index مسیرها، راهنمای جدید اجرا، فهرست اصلاحات، پرامپت‌ها و مراجع فنی قبلی.

جمع:۲۴بورد جدید +۴شیت کاراکتر. بوردهای اولویت‌دار بر طرح‌های پایه متناظر مقدم‌اند. در بورد۵۷–۵۸، دو ستون دیگر پیش‌نویس خانه نوجوان‌اند و با `TEEN_FINAL.png` جایگزین شده‌اند.

## آنچه تحویل نشده
این بسته ماکاپ تصویری و دستور اجراست. APK بازطراحی‌شده، سورس Android، مدل سه‌بعدی، Figma لایه‌باز یا منابع منفرد تمام آیکون‌ها در آن وجود ندارد. APK فعلی و ورودی‌های قبلی در بستهV4 باقی است؛ این ZIP بسته تازه طراحی است و آن فایل‌های حجیم را تکرار نمی‌کند.

برای همه۵۸صفحه، نمای پایه روز/شب وجود دارد؛ تمام۵۸صفحه برای تک‌تک سن‌ها و ظاهرها جداگانه تولید نشده‌اند. بورد بازی شامل۷نوع تعامل و۱صفحه نتیجه است و ادعای طراحی جداگانه تمام بازی‌های حدود۱۰۰تایی محصول را ندارد. برای چنین ادعایی فهرست واقعی بازی‌ها و routeهای سورس لازم است. تمام حالت‌های خطا/خالی/بارگذاری نیز برای همه ترکیب‌ها تصویر جدا ندارند.
