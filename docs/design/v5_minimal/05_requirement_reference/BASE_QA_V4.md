# محدودیت‌های شناخته‌شده و پذیرش

## آنچه باید اصلاح شود
- برخی واژه‌ها، نام‌ها، تقویم‌ها و عددهای نقاشی‌شده نادقیق‌اند؛ متن از نیازمندی معتبر بازنویسی شود.
- ترتیب ستون در بورد۱۷–۲۰ و بورد پایانی onboarding از راست است؛ از شماره چاپ‌شده و index استفاده شود.
- داک نمونه قدیمی صفحه۵ با خانه اصلاحی جایگزین شود. در بعضی بوردها nav والدین اشتباه است؛ پنج مقصد نوشتاری مبناست.
- تصویر مادر در نسخه اول تماس بیش از حد کودکانه است؛ بورد اصلاحی تماس و شیت خانواده جایگزین آن است.
- بوردهای روز/شب گاهی وضعیت انتخاب/محتوا/جزئیاتشان یکسان نیست؛ در اجرای واقعی تغییر تم فقط appearance را عوض کند و داده/route باقی بماند.
- شیت‌های RGBA هاله و آلفای نیمه‌شفاف دارند. شفافیت کانالی بررسی شده ولی تک‌تک cutoutها و لبه‌ها هنوز QA تولیدی ندارند.
- اندازه اصلی اغلب بوردها حدود۱۵۰۰px است و شامل۸صفحه است؛ خروجی تک‌صفحه ۴K یا فایل Figma لایه‌باز وجود ندارد. تصویر را مرجع ترکیب‌بندی بدان، نه اندازه‌گیری پیکسل دقیق.
- تصویرسازی سه‌بعدی، مدل mesh/rig یا انیمیشن آماده نیست. ۸حالت هر کاراکتر ۸رندر ثابت است.
- تصاویر صفحات اصلی برای یک حالت نمایشی‌اند؛ همه وضعیت‌ها و همه۴سن×۲ظاهر×۲تم برای۵۸صفحه جداگانه رندر نشده‌اند.
- وضعیت واقعی APK بررسی اجرایی/امنیتی نشده و تغییری نکرده است. سورس Android ضمیمه نیست؛ ZIP قدیمی شامل HTML/PNG است.
